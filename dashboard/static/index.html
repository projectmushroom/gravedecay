🎮 Gaming features & auto-throttle

    
This box does double duty — your agents work while you're away,
      and it's a console when you want to play. Auto-throttle makes the hand-off
      automatic, so you never have to flip modes yourself.

    
Turning this off also hides the dashboard's mode switcher,
      boot-mode row, and gaming actions, leaving a focused dev-box UI. This
      Settings control remains available so you can opt back in.

    
Launch a game → agent sessions are frozen in place (kept in
      RAM, provably zero CPU) and T3 Code + the database containers stop, handing
      all the RAM and GPU to the game.

    
Quit the game → everything thaws and resumes right where it
      left off, mid-thought.

    
Tailscale, SSH, this dashboard and the web terminal always stay
      up — the box is reachable even mid-game. Detection checks gamescope,
      Steam app cgroups, Feral GameMode, then an exact process-name fallback.
      It defaults on only on stock SteamOS, and your choice persists across
      upgrades. You can also toggle it with grave gamewatch on|off.
