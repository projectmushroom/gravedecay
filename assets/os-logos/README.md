# OS logos

Selected SVGs from [Font Logos](https://github.com/lukas-w/font-logos), pinned to `d3bf5d299e54595db1b19681a0cc57ab10454857`. Original artwork (with normalized line endings) is retained here under the accompanying Unlicense. Brand marks identify their respective operating systems/products.

Run `python3 scripts/build-os-logos.py` after changing these sources. It regenerates the dashboard sprite, Qt icons and shared Apple asset catalog; `--check` verifies they are in sync. No network access is needed to build or display the bundled logos.
